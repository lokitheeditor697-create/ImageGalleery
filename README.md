# ImageGallery

A responsive image gallery built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive grid layout for desktop and mobile.
- Hover effects with smooth transitions.
- Lightbox view with next/previous controls and keyboard navigation.
- Category filters (All, Nature, City, Abstract).

## Run locally
Open `index.html` directly in your browser, or serve the folder with:

```bash
python3 -m http.server 8000
```
